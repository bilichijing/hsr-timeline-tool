约定：

- **所有**网络请求必须经过本模块；请求失败（`httpx.RequestError` / `HTTPStatusError`）时回退到过期缓存（`cache.get(url, expired=True)`），无缓存则抛出原异常。
- 不要在 `core/` 里直接发请求。
- 跨线程调用必须走 `run_in_loop()`：UI 用一次性 `QThread` + worker `QObject`，worker 内 `run_in_loop(self._load())`。直接 `asyncio.run()` 会因 client 已绑定共享循环而报 "Event loop is closed"。
- `download_icon` 对已存在的目标文件直接返回（图标永久缓存，不做 TTL）。

### 1.2 `core/` 计算层

#### `core/av_system.py`（157 行）

```python
AV_PER_ACTION = 10000.0

@dataclass
class ActionEntry:
    unit_id: str          # 唯一标识（角色 unit_id / "enemy1" / "__aha__" / "__countdown_x__"）
    name: str
    speed: float
    current_av: float     # 无 __post_init__，必须显式传入
    is_monster: bool = False
    def reset_av(self) -> None: ...        # current_av = AV_PER_ACTION / speed

@dataclass
class ActionQueue:
    entries: list[ActionEntry] = field(default_factory=list)
    def add(self, entry: ActionEntry) -> None            # 直接 append，不去重
    def remove(self, unit_id: str) -> None
    def get(self, unit_id: str) -> ActionEntry | None
    def next_actor(self) -> ActionEntry                  # AV 最小；空队列 raise RuntimeError
    def advance(self) -> tuple[ActionEntry, float]       # 无参数！返回 (行动者, 消耗 AV)
    def apply_push(self, unit_id: str, rate: float) -> None   # AV ×(1+rate)，无上限钳制
    def apply_pull(self, unit_id: str, rate: float) -> None   # max(0, AV ×(1-rate))
    def update_speed(self, unit_id: str, new_speed: float,
                     advance_rate: float = 0.0, delay_rate: float = 0.0) -> None
    def snapshot(self) -> list[tuple[str, str, float, float]]  # (unit_id, name, speed, av) 升序
```

- `advance()` 的语义：先取 AV 最小者为行动者，**所有**单位（含行动者）扣减 `consumed = actor.current_av`，然后行动者 `reset_av()`。调用方自行累计 `total_av += consumed`。
- `update_speed()` 的官方换速公式（与《开发文档》6.1 一致）：

  ```
  old_base_av = 10000 / old_speed
  new_base_av = 10000 / new_speed
  new_av = 当前AV × new_base_av / old_base_av - new_base_av × (advance_rate - delay_rate)
  current_av = max(0.0, new_av)
  ```

- **不存在** `preview_order()` / `advance(av_consumed)` / `apply_push(unit_id: int, av_delta)` 这类早期设计中的签名。行动预览由 UI 层 `copy.deepcopy(action_queue)` 静态推演实现，不污染模拟器状态。

```python
    effect_hit, effect_res, energy_max, aggro, elation_dmg, laugh_bonus,

```

`final()` 的计算规则（**无任何钳制**，抗性钳制只在 `damage.calc_resistance` 里做）：

| 类别 | 规则 |
|---|---|
| 乘加区 | `hp/atk/defense/spd = base × (1 + pct) + flat` |
| 加法区 | `crit_rate`、`crit_dmg`、`break_effect`、`effect_hit`、`effect_res`、`energy_regen`、`outgoing_heal`、`incoming_heal`、`res_pen`、`follow_up_*`、`elation_dmg`、`laugh_bonus`、`laugh_point`、`good_joke` = `base + bonus` |
| 只取加成 | `dmg_bonus = bonus.dmg_bonus`（增伤是独立乘区，不与基础相乘） |
| 只取基础 | `energy_max`、`aggro`（`StatBonus` 里没有这两个字段，无法用 buff 改能量上限 / 仇恨） |
| 字典 | `elemental_dmg_bonus = dict(bonus.elemental_dmg_bonus)` —— **`BaseStats.elemental_dmg_bonus` 会被忽略**，分属性增伤只能从加成侧写入 |

**字段命名（易错）**：最终面板是 `defense`（不是 `def_`）、`spd`（不是 `speed`）、`crit_dmg`（不是 `crit_damage`）、`effect_res`（不是 `effect_resist`），`dmg_bonus` 是 **float** 而不是 dict。

`bp_need` 语义（`skill.py` 内注释原文）：**普攻 = 回复（数量 `bp_add`）；其余类型 = 不消耗**。

- 普攻：`sp_cost = -(bp_add or 1)`；战技 `sp_cost == 0` 时兜底为 `1`；非普攻的 `-1`（不消耗）归零。
- 终结技：`energy_cost` 取自 `raw["energy_cost"]`，为 0 时兜底 90；真实耗能由 `parse_all_skills(ultra_energy_cost=...)` 注入。

## 3. 错误处理规范

### 3.1 分层策略（现行实现）

| 层 | 现状 | 约定 |
|---|---|---|
| `api/` | 网络 / JSON 失败时**先回退过期缓存**；无缓存则抛出原始 `httpx` 异常或 `ValueError`，并已 `logger.error` 记录上下文 | 不吞异常；新增 API 函数须保持"回退 → 记录 → 抛出"的顺序 |
| `core/` | 参数非法时以**返回值**表达（如 `SkillPoint.consume()` 返回 `False`、`get_skill_by_type()` 返回 `None`）；未知伤害类型抛 `ValueError` | 不使用 `Result[T, E]`；不抛自定义异常层级 |
| `ui/` | 工作线程失败通过 `failed = Signal(...)` 回到主线程，用 `QMessageBox` 提示；配置字段解析失败用内嵌 `_int(value, default)` 回退默认值 | UI 层不得让异常逃逸到 `app.exec()`；提示文案写清"哪一步失败 + 影响" |

### 3.2 明确不做的

- 暂不引入 `AppError` / `ApiError` / `NetworkError` / `DataParseError` / `DomainError` / `InsufficientSPError` 异常类（早期设计稿中有，当前代码未实现）。若将来引入，需要一次性改造 `api/` 与 `ui/` 的调用点，并替换本节。

### 3.3 可恢复异常的处理范式

```python
# api/client.py 现行实现
try:
    r = await client.get(url); r.raise_for_status(); data = r.json()
except (httpx.RequestError, httpx.HTTPStatusError) as e:
    stale = cache.get(url, expired=True)
    if stale is not None:
        logger.warning("网络失败，使用过期缓存: {} | {}", url, e)
        return stale
    logger.error("请求失败且无缓存: {} | {}", url, e)
    raise
```

```python
import pytest

from src.core.av_system import AV_PER_ACTION, ActionEntry, ActionQueue


class TestActionQueue:
    def test_next_actor_min_av(self):
        # Arrange
        q = ActionQueue()
        q.add(ActionEntry("c1", "C1", speed=100, current_av=80))
        q.add(ActionEntry("c2", "C2", speed=134, current_av=74.6))
        # Act
        actor = q.next_actor()
        # Assert
        assert actor.unit_id == "c2"

    def test_next_actor_empty_raises(self):
        q = ActionQueue()
        with pytest.raises(RuntimeError):
            q.next_actor()

    def test_advance(self):
        """AV 最小者先行动；所有单位扣减；行动者重置。advance() 无参数。"""
        q = ActionQueue()
        q.add(ActionEntry("c1", "C1", speed=100, current_av=100))
        q.add(ActionEntry("c2", "C2", speed=134, current_av=74.6))
        actor, consumed = q.advance()
        assert actor.unit_id == "c2"
        assert consumed == pytest.approx(74.6)
        assert q.get("c1").current_av == pytest.approx(100 - 74.6)   # 其余扣减
```

```python
from src.core.damage import DamageContext, DamageType, DefenseContext, calculate_damage
```

校准注意：

## 6. UI 开发规范

### 6.1 命名

- 主窗口：`BattleSimulatorWindow(QMainWindow)`（当前唯一主窗口）。
- 对话框：`<功能>Dialog(QDialog)`，如 `CharacterPickerDialog`、`LightconePickerDialog`、`RelicPickerDialog`、`RelicConfigDialog`；结果通过属性 + `exec() == QDialog.Accepted` 返回（不强求自定义信号）。
- 选择器类对话框（角色 / 光锥 / 遗器套装）统一形态：顶部「搜索 + 下拉筛选」→ 图标网格 `QListWidget(IconMode)` → 底部详情 + `确认 / 取消`；数据与图标由 `QThread` + worker `QObject` 异步加载，`done()` / `closeEvent` 里统一停线程。
- 自定义控件：`<功能>Widget(QWidget)`，如 `TimelineGanttWidget`、`DamagePieChartWidget`、`SPIndicatorWidget`、`EnergyOrbWidget`、`EnemyTargetWidget`。
- 私有辅助类以 `_` 前缀（如 `_CharacterDetailWorker`、`_WheelBlocker`）；模块级工具函数放文件顶部（如 `make_preset_character`、`make_card`）。

### 6.2 信号约定

- 信号名用**动词过去时**或状态名，参数尽量少：`action_hovered = Signal(str, str)`、`clicked = Signal(str)`、`loaded = Signal(int, object)`、`failed = Signal(int, str)`。
- 无参数信号（如 `EnergyOrbWidget.clicked`）在主窗口里用 `lambda idx=i` 闭包绑定行号，避免自定义带参信号。
- 后台 worker 统一 `loaded` / `failed` 双信号；主线程收到后再更新 UI。

### 6.3 主题与样式

- 所有颜色集中在 `ui/theme.py` 的 `class Colors`（背景 6 色 / 文字 3 色 / 主色金 3 色 / 强调 4 色 / 边框 2 色 / 7 属性色 / 9 命途色），QSS 用 f-string 插值。
- `DARK_STYLE`（约 440 行）覆盖 QWidget / QMainWindow / QScrollBar / QPushButton（`#primaryBtn`、`#dangerBtn`）/ 输入控件 / QTableWidget / QListWidget / QLabel（`#title`、`#subtitle`、`#sectionLabel`）/ 侧栏（`#sidebarHeader`、`#liveBadge`、`#previewPanel` 等）/ QGroupBox / QTabWidget / QMenu / QToolTip / QCheckBox / QProgressBar。
- 映射表：`PATH_COLORS`、`ELEMENT_COLORS`（键为英文原始值）。
- 约定：**不在控件里硬编码颜色**；确需内联 QSS 时必须引用 `Colors.*`。

### 6.4 长任务处理（现行范式）

```python
class _DetailWorker(QObject):
    loaded = Signal(int, object)
    failed = Signal(int, str)

    def run(self) -> None:
        try:
            payload = run_in_loop(self._load())      # 共享 asyncio 循环
        except Exception as e:                       # noqa: BLE001
            self.failed.emit(self._row, str(e))
        else:
            self.loaded.emit(self._row, payload)
        finally:
            QThread.currentThread().quit()

# 主窗口
thread = QThread()
worker = _DetailWorker(row, char_id)
worker.moveToThread(thread)
thread.started.connect(worker.run)
worker.loaded.connect(self._on_detail_loaded)
thread.start()
self._detail_workers[row] = worker      # 必须持有引用，否则被 GC 回收导致线程空跑
```

### 6.5 交互与输入

- 交互页快捷键由应用级 `eventFilter` + `MainWindow.keyPressEvent` 统一接管（`空格`/`回车` 推进、`Q` 普攻、`E` 战技、`1~4` 终结技），仅在"交互模拟"Tab（`currentIndex() == 1`）且无模态窗口时生效。
- 键盘交互区内的按钮统一 `setFocusPolicy(Qt.NoFocus)`，避免抢焦点。
- 数值输入控件通过 `_disable_wheel_inputs()` 装 `_WheelBlocker`（QSS 同时把 QSpinBox 的上下箭头宽度设为 0），防止误滚改值。

### 6.6 控件复用

- 通用控件放 `ui/widgets/`；主窗口内联的小面板（侧栏、卡片）用模块级辅助函数（`make_card`）保持文件内聚。
- 禁止在 `.py` 里硬编码样式；统一走 `theme.py`。

## 8. Web 端规范

Web 端与桌面端**平级**：都只能依赖 `core` / `api`，不得互相导入（`src/web` 不导入 `src/ui`，反之亦然）。

### 8.1 依赖与启动

- **只允许 Python 标准库做服务端**（`http.server` / `json` / `threading` / `urllib`）；不新增 FastAPI、Flask、uvicorn、websockets 等依赖，也不引入 Node 构建链。
- 入口：`web_main.py`（`--host` / `--port` / `--open`），默认 `127.0.0.1:8765`；桌面端 `ui_main.py` 不受影响，两者可同时运行。
- 监听地址默认只绑本机；`--host 0.0.0.0` 时没有鉴权，属于使用者自担风险的行为。
- 前端静态资源固定在 `src/web/static/`，`server.py` 用 `Path.resolve()` + 父目录校验防路径穿越。

### 8.2 接口约定

| 项 | 约定 |
|---|---|
| 成功响应 | `POST` 返回 `{"message": str, "state": <完整状态>}`；`GET /api/state` 直接返回状态 |
| 失败响应 | HTTP 400 + `{"error": "中文原因"}`（`WebError`）；未捕获异常 → 500 + `{"error": ...}` 并打印堆栈 |
| 状态结构 | `{"rows": [...], "config": {...}, "sim": <交互模拟视图或 null>, "result": <结果视图或 null>, "message": str}` |
| 前端状态 | `app.js` 只保存当前 Tab 与选中日志行；**任何写操作后都以返回的 `state` 整体重渲染**，不在前端做业务计算 |
| 数值计算 | 面板 / 战斗构造 / 模拟控制全部在 `session.py`，复用 `core`；`views.py` 只做格式化与派生展示（甘特 lanes、饼图百分比、卡片） |
| 并发 | 模块级 `SESSION_LOCK`（`RLock`）串行化所有写操作；单用户场景不做多会话 |
| 缓存 | `./cache/web_state.json`（`version: 1`）；读取失败回退默认，写入失败静默忽略（不阻断服务） |

### 8.3 前端约定

- 原生 ES Module，模块职责见 `docs/开发文档.md` §12.5；禁止引入 npm 包或 CDN 资源。
- 所有插入 HTML 的文本必须经 `esc()` 转义；用户可控值不得直接拼进 `innerHTML`。
- 图表用 Canvas（甘特）/ SVG（饼图）手绘，不依赖图表库；甘特滚轮缩放 0.5x~8x，拖动平移。
- 键盘快捷键与桌面端一致：`空格`/`回车` 推进、`Q` 普攻、`E` 战技、`1~4` 终结技；模态框打开或焦点在输入控件内时不触发。
- 换肤 / 主题目前只有深色一套（与 `src/ui/theme.py` 的 `Colors` 对齐），新增颜色请同时更新 `css/app.css` 的 `:root` 变量。
- 新增遗器部位 / 词条文案时改 `core/relics/labels.py`（两端共用），不要在 JS 里重复维护。

### 8.4 测试要求

- 后端改动需补 `tests/test_web_api.py`：纯逻辑（`Session` / `views`）+ 真实 `ThreadingHTTPServer` 路由各覆盖一遍。
- 单测不打真实 nanoka 网络：涉及目录 / 详情的接口只验证"不依赖网络"的部分。
- 前端改动至少手动回归：7 个 Tab 渲染、角色 / 光锥 / 遗器选择器、freesr 导入、一次性模拟、交互模拟（推进 / 普攻 / 战技 / 终结技 / 回溯）、甘特缩放平移、饼图数据。

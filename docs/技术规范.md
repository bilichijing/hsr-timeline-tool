## 3. 错误处理规范

### 3.1 分层错误策略

| 层 | 错误类型 | 处理方式 |
|---|---|---|
| `api/` | 网络错误、JSON 解析错误 | 抛出 `ApiError`，由 UI 层捕获并提示 |
| `api/` | 缓存未命中且请求失败 | 尝试回退到旧缓存，无则抛出 |
| `core/` | 参数非法（如 SP 不足） | 返回 `Result[T, Error]` 或抛出 `DomainError` |
| `ui/` | 任何异常 | 捕获后用 QMessageBox 提示用户，记录日志 |

### 3.2 自定义异常

```python
class AppError(Exception):
    """所有应用异常的基类"""
    def __init__(self, message: str, cause: Exception | None = None):
        super().__init__(message)
        self.cause = cause

class ApiError(AppError):
    """API 层错误"""
    pass

class NetworkError(ApiError):
    """网络请求失败"""
    pass

class DataParseError(ApiError):
    """数据解析失败"""
    pass

class DomainError(AppError):
    """业务逻辑错误"""
    pass

class InsufficientSPError(DomainError):
    """战技点不足"""
    pass
```

### 3.3 API 层错误处理示例

```python
async def fetch_character_detail(char_id: str) -> dict:
    url = f"{DATA_BASE}/{get_latest_version()}/zh/character/{char_id}.json"
    try:
        return await fetch_json(url, expire=CacheTTL.DETAIL)
    except httpx.RequestError as e:
        # 尝试回退到过期缓存
        stale = cache.get(url, expired=True)
        if stale:
            logger.warning(f"网络失败，使用过期缓存: {char_id}")
            return stale
        raise NetworkError(f"无法获取角色 {char_id}", e)
    except json.JSONDecodeError as e:
        raise DataParseError(f"角色数据解析失败: {char_id}", e)
```

### 4.2 日志级别使用约定

| 级别 | 使用场景 |
|---|---|
| `DEBUG` | 详细计算过程（伤害公式各步骤、AV 计算） |
| `INFO` | 正常流程（数据加载完成、工程保存） |
| `WARNING` | 可恢复异常（缓存回退、数据缺失用默认值） |
| `ERROR` | 不可恢复异常（请求失败且无缓存） |
| `CRITICAL` | 程序崩溃级别（数据库损坏、配置丢失） |

### 4.3 日志内容规范

```python
# ✅ 好：带上下文
```

### 5.2 测试约定

- **命名**：`test_<被测函数>_<场景>_<预期>`，如 `test_compute_damage_with_crit_returns_2x`
- **结构**：Arrange-Act-Assert 三段式
- **覆盖**：每个公共函数至少 3 个测试（正常 / 边界 / 异常）
- **数据**：API 测试用 fixtures JSON，不打真实网络

### 5.3 测试示例

```python
# tests/test_core/test_av_system.py
import pytest
from src.core.av_system import ActionQueue, ActionEntry

class TestActionQueue:
    def test_next_actor_returns_min_av(self):
        # Arrange
        queue = ActionQueue([
            ActionEntry(1, speed=100, current_av=50),
            ActionEntry(2, speed=120, current_av=80),
        ])
        # Act
        actor = queue.next_actor()
        # Assert
        assert actor.unit_id == 1

    def test_advance_resets_actor_av(self):
        queue = ActionQueue([
            ActionEntry(1, speed=100, current_av=50),
            ActionEntry(2, speed=120, current_av=80),
        ])
        queue.advance(50)
        # 行动者（unit 1）重置为 10000/100=100
        assert queue.entries[0].current_av == 100.0
        # 其余减去 50
        assert queue.entries[1].current_av == 30.0

    def test_apply_pull_clamps_to_zero(self):
        queue = ActionQueue([
            ActionEntry(1, speed=100, current_av=50),
        ])
        queue.apply_pull(1, 100)  # 拉条 100
        assert queue.entries[0].current_av == 0
```

```python
from PySide6.QtCore import QThread, Signal

class DataLoadWorker(QThread):
    progress = Signal(int, str)   # percent, message
    finished = Signal(dict)       # result
    error = Signal(str)

    def run(self):
        try:
            self.progress.emit(10, "获取版本...")
            version = get_latest_version()
            self.progress.emit(30, "加载角色列表...")
            characters = await fetch_character_list()
            self.progress.emit(100, "完成")
            self.finished.emit({"version": version, "characters": characters})
        except Exception as e:
            self.error.emit(str(e))
```

```python
from pydantic import BaseModel
from pathlib import Path
import appdirs

class WindowSettings(BaseModel):
    width: int = 1280
    height: int = 800
    x: int = 100
    y: int = 100

class Settings(BaseModel):
    theme: str = "dark"
    language: str = "zh-CN"
    data_version: str = ""
    last_project: str = ""
    window: WindowSettings = WindowSettings()
    cache_dir: str = ""

    @classmethod
    def load(cls) -> "Settings":
        path = cls.settings_path()

    @staticmethod
    def settings_path() -> Path:
        return Path(appdirs.user_config_dir("HSR排轴工具")) / "settings.json"

    def save(self):
        path = self.settings_path()
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_text(self.model_dump_json(indent=2), encoding="utf-8")
```

接下来添加使用freesr-data.json导入角色面板配置的功能。我来为你介绍freesr-data.json。
freesr-data.json是常用的存储《崩坏：星穹铁道》游戏角色配置的文件，包含了角色、角色携带的遗器和角色携带的光锥，分别对应其中的avatars、relics、lightcones字段。
我已经为你准备了一个简单的freesr-data.json文件，它包含了我配置好的角色不死途的面板。
先看avatars中的信息，不死途的角色id是1504，因此我们在avatars找到编号1504，接下里我来逐个为你解释其中各个字段的信息。
"avatar_id": 1504,这是角色的id。（和nanoka中完全对应，这是角色不死途的id）
"data": {
    "rank": 2,
    "skills": {
        "1504001": 6,
        "1504002": 10,
        "1504003": 10,
        "1504004": 10,
        "1504007": 1,
        "1504101": 1,
        "1504102": 1,
        "1504103": 1,
        "1504201": 1,
        "1504202": 1,
        "1504203": 1,
        "1504204": 1,
        "1504205": 1,
        "1504206": 1,
        "1504207": 1,
        "1504208": 1,
        "1504209": 1,
        "1504210": 1
    },
这里的rank代表了角色的星魂等级，skills中1504001是普攻等级，1504002是战技等级，1504003是终结技等级，1504004是天赋等级。
不死途不是记忆命途或欢愉命途的角色，因此没有忆灵技或欢愉技等级。skills中其余数值为秘技、额外能力和行迹属性加成对应的等级，我们先暂时默认全部固定为1。
"skills_by_anchor_type"我暂时不知道代表什么意思
"level": 80,这是角色等级。我们暂时默认只有80一个可能的值，不考虑其他等级。
"promotion": 6,这是角色晋升等级。我们暂时默认只有6一个可能的值，不考虑其他等级。
"sp_max": 150,这是角色能量上限。
"sp_value": 75,这是角色进入战斗时的初始能量值。
"techniques": [
    150401
]
这是角色秘技对应的编号。

我们以前面给出的sub_affixes字段为例
"sub_affix_id": 2说明这是攻击力词条，"count": 2说明该词条强化了2次，属性先计算为16.935*2（最低档数值*count），"step": 0说明强化全部是最低档，所以16.935*2就是这条属性的最终数值。
"sub_affix_id": 3说明这是防御力词条，"count": 2说明该词条强化了2次，属性先计算为16.935*2，"step": 2说明我们还需要将16.935*2加上(19.052-16.935)*2才是最终数值（(第二档强化数值-第一档强化数值)*step）
